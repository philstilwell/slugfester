# Slugfester Replacement Held-Out Discovery Gate v4.2.21.17.15

The five replacement held-out debates produce eighteen isolated score-blind discovery contexts. The gate uses 5.6 Sol at low reasoning through the ChatGPT subscription, removes API credentials, permits one attempt per context, prohibits retry and semantic repair, and schedules no more than four contexts concurrently in deterministic input order.

Every structured-output schema constrains candidate start events to the owned core and candidate end events to the available context. The unchanged deterministic validator provides a second enforcement layer. Other chunks, other model outputs, prior judgments, legacy assessments, scores, winners, and publication prose remain unavailable to each context.

After all eighteen outputs validate, deterministic compilation transports every discovered candidate without semantic deduplication. Each debate must contain at least eight candidates and at least four per side. No score is derived. Passing authorizes only preparation of two independently anonymized judgment packets per debate.
