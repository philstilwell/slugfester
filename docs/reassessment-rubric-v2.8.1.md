# Slugfester Reassessment Rubric v2.8.1

This classification-only rubric applies Workflow v2.8.1. It contains no performance scores and cannot authorize Overall Commentary, AI Extension, rankings, or production changes.

## One-pass order

For each locked responsive move, complete exactly one primitive pass:

1. map the target as `direct`, `connected-example`, or `object-change`;
2. classify scope, then burden;
3. classify every indispensable component independently;
4. identify contrary material only when every component operation is null;
5. classify an expressly cued defect and its object;
6. classify separately evidenced impact;
7. classify the two reframe primitives;
8. identify evidenced eligible burden bridges; and
9. allow code to derive every downstream label.

Do not reason backward from a desired coverage, diagnostic, reframe, or burden result.

## Required evidence anchors

Use the shortest complete clause that preserves controlling negation, modality, quantifier, comparison, condition, and named referent. Every positive or changed primitive requires its own exact span. A missing required span invalidates the annotation.

## Mapping anchors

- `direct`: the response speaks directly about the target proposition; no mapping span is required.
- `connected-example`: another case is expressly presented as an instance, analogy, counterexample, or model of the target; cite the connection.
- `object-change`: the response changes subject, referent, comparison class, baseline, or question type; cite the new element.

An expressly mapped counterexample remains the same target. A merely adjacent illustration does not.

## Scope anchors

Modal scale changes take precedence. Classify “cannot” versus “does not normally” as `modality-shift`. Use `narrowed` or `strengthened` only for a nonmodal range, time, population, condition, quantifier, or strength change. A preserved non-same scope must have a qualifying or distinguishing component operation.

## Burden anchors

Retain the burden by default. Reassignment needs an express transfer of the same demand; replacement needs an express new success condition. Counterquestions, “my point is,” redirection, historical characterization, and competing arguments are excluded unless the transfer or replacement is stated.

## Operation anchors

- `denies`: says the component itself is false.
- `qualifies`: restricts the component's truth conditions.
- `distinguishes`: partitions its meanings, cases, referents, comparisons, or categories.
- `explains`: accepts it as a datum and supplies why or how.
- `accepts`: a bare grant or reliance after the more specific tests fail.
- `undermines`: attacks warrant, inference, baseline, analogy, or evidential force without direct falsity.
- null: no exact operation.

Use that order. In particular, “there is no evidence for X” undermines a claim that X is evidence; it does not deny that a speaker called X evidence. Supplying a mechanism is `explains`, not merely `accepts`.

## Diagnostic anchors

Select a non-none defect only when the excerpt itself supplies the cue:

- disowned attribution → `attribution-error`;
- explicitly incompatible commitments → `contradiction`;
- explicitly unstable readings or meanings → `ambiguity`;
- expressly excessive range or modality → `scope-mismatch`;
- missing or nontransferable comparison → `unsupported-comparison`;
- named required but absent support → `missing-premise`;
- expressly non-following conclusion with premises left standing → `invalid-inference`;
- expressly non-warranting evidence → `evidential-insufficiency`; or
- expressly nonbearing material → `irrelevance`.

Apply this list in order. Counterargument alone means `none`.

Use a component object only for a cue attached to one named component. Use the packet only for an express whole-argument or multi-component cue. Do not infer a broader object from downstream consequences.

## Impact and reframe anchors

`inferential-consequence` states what fails or is limited. `verdict` merely evaluates. `none` is the default. The impact span must contain the consequence, not just the criticism cue.

A reframe requires both a stated defect in the original demand and a stated replacement demand. Questions or redirections without both clauses fail.

## Derived result

Code derives disposition, substitution cause, target coverage, diagnostic, reframe, and burden relation. Annotators never enter or revise those outputs.
