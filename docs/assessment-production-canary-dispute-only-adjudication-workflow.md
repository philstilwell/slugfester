# Slugfester production-canary disputed-fields-only adjudication workflow

Prepare one isolated third-pass context for each production-canary debate. Every context contains only disputed fields, independently anonymized candidate pairs, locked transcript evidence, and the raw verified diarized transcript for a move when audio verification was mandatory. Candidate provenance, Pass A and Pass B identities and rationales, nondisputed fields, aggregate scores, winners, legacy assessments, other debates, and publication prose remain unavailable.

Every required pair must be selected exactly once. The adjudicator may choose only an entire candidate object; it may not average, interpolate, rewrite, repair, or invent values. Importance remains a judgment field because the score-blind inventory did not fix it. Strict burden-adjustment exclusion remains in force.

Use 5.6 Sol with low reasoning effort through the ChatGPT subscription. The response schema and deterministic validator require complete dispute coverage, whole dependency-pair selection, legal candidate values, and zero scores. Passing packet preparation authorizes only a frozen adjudication execution manifest; it does not authorize model execution, final-ledger assembly, scoring, publication, production mutation, or remaining production batches.
