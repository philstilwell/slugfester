# Slugfester Partition Discovery Failure Analysis v4.2.21.11.1

The frozen twelve-context discovery gate completed 11 valid contexts and one deterministic validation failure. Debate 182 chunk 4 named an earlier same-side candidate as one of a reply's local targets. The manual already prohibited this topology, and the validator correctly rejected it. No retry, output repair, candidate compilation, primary judgment, or score was authorized.

The failure reveals unnecessary coupling in score-blind discovery. Discovery needs to identify whether a passage is constructive or responsive and describe its earlier target; it does not need to create selected-move target IDs. Primary Pass A later decides which candidates enter the bounded inventory and is therefore the proper owner of target topology.

The successor schema removes local target IDs, reduces response intent to `constructive` or `reply`, requires a prose target description for every reply, and continues to let the repository derive only `moveKind`. All twelve contexts must be rerun under a new preregistration; the eleven accepted predecessor outputs are not reused.
