# Slugfester Atomic-Bundle Correction-Smoke Workflow v3.7.3

Version 3.7.3 defines a candidate-bound correction smoke on the eight exposed v3.7.2 bundles. It tests whether complete atomic choices eliminate scalar incoherence. Because the cases are exposed development material, success can authorize only a later disjoint retired test—not a corrected benchmark key, held-out access, scoring, prose, or production use.

Two isolated 5.6 Sol contexts are planned per debate. Candidate positions are counterbalanced and origins are hidden. Complete bundle values are compared after both initial passes close. A third isolated context may see only disputed bundles. Every final bundle requires two agreeing votes.

Target candidates contain only independent component judgments; contrary disposition is derived mechanically. Diagnostic and reframe candidates are prevalidated complete tuples. Model outputs select one anonymous bundle option with exact source evidence and rationale. There is one attempt per context, no retry or repair, and scores are prohibited.
