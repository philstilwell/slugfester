# Slugfester Hard-Route Score-Blind Inventory Gate v4.2.21.17.24

Before performance judgment, one isolated 5.6 Sol curator per debate reviews the complete recovered discovery inventory and locks only argument structure: burden routes, four to six weighted issue sections, and eight to twenty-four source-supported moves. The curator cannot rate performance, identify response targets, calculate scores, name a winner, write Overall Commentary, or create an AI Extension.

All discovered candidates remain available. Each is deterministically furnished with a source-exact excerpt, then projected through the retired-tested inventory transport that omits only validator-owned metadata restored after selection. Candidate identity, side, speaker, chronology, proposition, load-bearing rationale, response intent, context summary, and evidence remain present. This is field projection, not semantic downselection.

The five contexts receive one attempt each, no retry or repair, under a one-to-two concurrency ramp and a ten-minute per-context limit. Every proposal must compile against the full hash-locked evidence bundle; final evidence is rerendered from local transcript events. Passing all five inventories authorizes preparation, but not execution, of two byte-identical isolated performance-judgment packets per debate. No score is derived.
