# Slugfester Reassessment Rubric v4.0.1

This amendment inherits the complete v4.0 rubric. It changes only who selects the precision/clarity and epistemic-calibration scalar values.

For precision, the model records proposition recoverability, term stability, scope stability, qualification explicitness, and a source-grounded rationale. Repository code maps the resulting v4.0 band to its fixed representative value: 95, 85, 75, 60, or 35.

For calibration, the model records asserted force, warrant fit, qualification status, uncertainty acknowledgment, and a source-grounded rationale. Repository code maps the resulting v4.0 band to its fixed representative value: 95, 85, 75, 60, or 35.

The model must not emit either scalar. A validator or calculator that accepts a model-supplied value, uses a different mapping, or changes the closed findings after ratings become visible fails the protocol. All other anchors, penalty controls, aggregation weights, and burden-completion exclusions remain unchanged.
