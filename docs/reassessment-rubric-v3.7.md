# Slugfester Reassessment Rubric v3.7

This calibration rubric inherits the v3.6.3 evidence and family rules.

## Target granularity

`directTarget` is residual whole-target contact: use it only when exact response language bears on the locked target as a whole and the contact is not already represented by a component, scope, example, or contrary decision. Component contact requires explicit propositional contact with that component. Do not distribute generic assent, and do not mark a second component merely because it is logically implied, complemented, or excluded by language assigned to another component.

An example already instantiated within the locked target is `inside-locked-target`; only a distinct case expressly connected to the target is `distinct-connected-example`. Any positive component requires `component-contact-precludes-contrary`. `relevant-no-component` requires zero positive components.

## Other families and evidence

Diagnostics require an explicit defect cue. A consequence requires a distinct clause and an explicit unique relation cue. A dual-positive reframe requires explicit malformed-demand and replacement-demand cues joined by a unique relation cue. Burden conflicts are candidate-bound.

Every active evidence string must occur exactly once as a raw, case-sensitive substring, including occurrences within longer words. Expand short strings with adjacent exact source text until unique. Inactive and exclusion evidence is null.

Return only the requested batch object. Do not emit participant scores, critique prose, winners, Overall Commentary, AI Extension, or legacy assessment material.
