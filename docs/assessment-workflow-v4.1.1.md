# Slugfester Bounded Lean Workflow v4.1.1

This prospective amendment inherits v4.1 and changes only the burden-ID namespace used by burden-completion eligibility records.

`affectedBurdenIds` may name either a route ID or a bridge ID declared in the same output. A route ID names the debate-side burden governed by that route's observable success criterion; a bridge ID names the motion, central, or subsidiary component burden. Any other identifier fails validation.

This option applies only to v4.1.1 validation. The frozen v4.0.1 and v4.1 validators retain their original behavior. All bounded-inventory, source, model-allocation, scoring, audio, trigger, compute, AI Extension, and promotion rules remain unchanged.

- `protocolId: v4.1.1-bounded-lean-risk-triggered-consensus`
