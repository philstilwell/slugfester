# Slugfester Reassessment Rubric v3.3

Rubric v3.3 preserves the v3.2 semantic taxonomy and sharp scoring boundaries while requiring de novo, anonymous, bundle-coherent adjudication.

## Default-first field rules

- **Target contact:** true only when exact response language bears on the locked proposition or an indispensable component. Topic similarity and shared vocabulary are insufficient.
- **Connected example:** true only for a distinct case, analogy, counterexample, or model expressly connected to the target. A mere illustration or named person already inside the target is insufficient.
- **Scope:** change `same` only for an explicit change in the range or modality of the same contacted proposition. Redirection, a different question, or another evaluative concern is not narrowing, strengthening, or modality shift.
- **Burden adjustment:** retain unless the same demand is expressly transferred (`reassigned`) or a materially different governing success condition is expressly installed (`replaced`). Counterargument, support request, subsidiary issue, or narrower conclusion does not qualify.
- **Component contact:** judge each indispensable proposition independently. Granting, using, denying, restricting, distinguishing, explaining, questioning its warrant, or expressly challenging it qualifies. Lexical overlap and contact with a dependent component do not.
- **Relevant contrary material:** true only when no component is contacted and exact response language nonetheless supplies contrary material bearing on the target.
- **Burden contact:** choose the highest eligible bridge expressly supported or attacked. Critical attack and constructive support count symmetrically; topic contact alone does not.

## Diagnostic bundle

Choose the first defect clearly expressed: `attribution-error`, `contradiction`, `ambiguity`, `scope-mismatch`, `unsupported-comparison`, `missing-premise`, `invalid-inference`, `evidential-insufficiency`, or `irrelevance`; otherwise choose `none`.

A denial, counterposition, request for detail, example, or alternative question is not itself a diagnostic defect. Consequence is true only when a separate clause says what fails, does not follow, is not established, does not explain, cannot carry the claimed weight, or must be limited because of the defect. Consequence true requires a non-`none` defect.

## Reframe bundle

Malformed demand is true only when the response explains why the governing framing or demand is defective. Replacement demand is true only when it states a replacement governing demand or success condition. A different topic, narrower claim, or more interesting question is insufficient. A complete reframe requires both primitives.

## Bundle invariants

- Target false forces every component false, contrary material false, scope `same`, and defect `none`.
- Any component true forces target true and contrary material false.
- Contrary material true requires target true and every component false.
- A non-`same` scope or non-`none` defect requires target true.
- Consequence true requires a non-`none` defect.
- Defaults require null evidence; nondefaults require an exact supporting response substring.

## Later scoring anchors

Responsiveness is constrained by the final structural classification: full coverage or a complete decisive diagnostic/reframe permits 80–100; partial coverage 55–79; relevant nonanswer 40–69; nonanswer 0–39. A partial answer cannot receive full-answer credit merely because its contacted component is strong.

Relevance and burden are constrained by the highest eligible bridge actually supported or attacked: motion completion 90–100; central bridge 75–89; subsidiary bridge 55–74; topical/peripheral 25–54; unadopted or irrelevant 0–24.

Charity means accurately engaging the strongest live version licensed by the record, not inventing premises, repairs, or concessions. A charitable reconstruction may improve prose explanation but cannot change a primitive without explicit source support.

The debate-wide burden-completion adjustment defaults to zero. It is eligible only when it changes an explicit debate-wide success criterion, is distinct from every selected-move judgment, and is absent from all other dimensions, weights, omissions, and adjustments. If any exclusion fails, the adjustment is zero.

## Anonymous adjudication rule

Judge the packet without inferring raw-pass identity, agreement, conflict, or likely candidate values. Complete the semantic judgment and exact evidence first. Candidate mapping occurs only after the model context closes. Philosophical plausibility, sophistication, or a preferred reconstruction cannot substitute for explicit source support.
