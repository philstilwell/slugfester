# Slugfester Recovery Primary Gate v4.2.19.2

This gate tests the v4.2.19 deterministic recovery contract on the disjoint, frozen, dyadic Debates 110, 147, and 194. The corrected v4.2.19.1 screening changed only a redundant morality-anchor regular expression; it did not change the sample, classifier, route measurements, or ranks.

Each debate receives one isolated 5.6 Sol primary pass at low reasoning effort through the user's ChatGPT subscription. Every context contains only the three locked rubric documents, the v4.2.19 manual and schema, its packet, and its complete compact timestamped source ledger. API keys, other debates, prior judgments, scores, winner labels, control identity, and publication prose are unavailable.

The repository validates exact evidence cues, compiles bounded verbatim excerpts, orders moves chronologically, validates reply edges after ordering, derives response classes from component findings, and maps only the within-class responsiveness position. These are preregistered mechanical operations, not post-hoc corrections. Invalid raw output is preserved and rejected. There is one attempt per debate, no retry, no correction pass, no semantic normalization, and no score derivation.

The process timeout is 15 minutes per context. Operational acceptance additionally requires no valid context above 10 minutes and a valid-context mean no greater than 7.75 minutes. Independent contexts continue after a failure so that the gate retains diagnostic value.

Medium-confidence move attributions are recorded for mandatory audio verification before any later adjudication or score derivation. The hidden control is unavailable to the primary judge and exists only to force a later independent-pass and adjudication-path exercise if this primary gate succeeds.

A complete three-of-three semantic and timing pass authorizes design and preparation of the v4.2.19-compatible independent Pass B, deterministic disagreement extraction, disputed-field adjudication, and medium-confidence audio-verification stage. It does not authorize those model calls, score derivation, production mutation, or the 195-debate run.
