# Slugfester Corrected Fresh Direct-Lane Judgment Gate v4.2.18.1

The frozen v4.2.18 source-only sample was rejected before packet preparation because a free-will motion phrased in terms of control, available actions, freedom, and responsibility did not match the inherited `mind-agency` classifier and therefore fell into the general residual family. No candidate transcript, audio, legacy assessment, or model context was opened.

This replacement selector adds a narrow mind-and-agency rule for that wording, changes the fixed salt, and excludes all three debates whose ranks were exposed by the rejected sample. It otherwise preserves the v4.2.18 boundary: three dyadic debates under 90 minutes, complete local transcript chains, three distinct topic families, no legacy content, and minimum aggregate deterministic hash rank. A new motion-only screen must pass before packet construction.

If screening passes, the packet, primary schema, hidden-control selection, source-integrity rules, one-attempt policy, and authorization limits are identical in substance to v4.2.18. This stage prepares but does not execute model judgments, derive scores, mutate production data, or authorize the 195-debate run.
