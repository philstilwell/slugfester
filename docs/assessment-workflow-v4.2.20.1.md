# Slugfester Source-Span Primary Gate v4.2.20.1

This gate tests v4.2.20 on the disjoint dyadic Debates 27, 188, and 195. Each passed both direct-route ceilings and an independent motion-family screen. The hidden control is unavailable to the primary judge.

Each debate receives one isolated 5.6 Sol pass at low reasoning effort through the user's ChatGPT subscription. The context contains only the three locked rubric documents, v4.2.20 manual and schema, debate packet, and complete compact timestamped ledger. Other debates, prior judgments, scores, winner labels, publication prose, and API keys are unavailable.

The model supplies semantic source spans but no evidence text. The repository renders bounded verbatim evidence, owns chronology, rejects every future or unknown response target without repair, derives response class, and maps within-class responsiveness. There is one attempt per debate, no retry, no correction, no semantic normalization, and no score derivation.

The process timeout is 15 minutes per context. Operational passage requires each valid context at or below 10 minutes and a valid-context mean at or below 7.75 minutes. Medium-confidence attributions remain mandatory audio-verification triggers before later adjudication or score derivation.

A three-of-three semantic and timing pass authorizes design and preparation—but not execution—of the matching independent Pass B, disagreement extraction, audio verification, and disputed-field adjudication. It does not authorize scores, publication, or the 195-debate run.
