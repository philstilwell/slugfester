# Slugfester Replacement Held-Out Source Preparation v4.2.21.17.14

The replacement five are converted mechanically into hash-locked source packets, complete compact ledgers, and isolated discovery chunks. Direct-route debates are split into at least two chunks so every debate uses the same score-blind discovery contract.

Every generated output schema now bounds a candidate's start event to its chunk's owned core and its end event to the available context. Preparation replays those bounds, every source event, every chunk ledger, and every source hash. It reads no transcript semantically and makes no model, audio, adjudication, or scoring call.

Passing this preparation authorizes only a frozen discovery execution manifest. It does not authorize model execution by itself or any downstream assessment stage.
