# Slugfester No-Truncation Finalization Gate v4.2.17

This retired replication gate reruns Debates 55, 103, and 161 after the v4.2.16 guarded-schema failure. Each fresh 5.6 Sol/low context receives the current workflow, locked scoring rubric, finalization manual, complete source packet, and a debate-specific closed schema. The packet contains every source-grounded move, route, section, audio-verified representative quotation, and calculated score. Participant judgment remains closed, raw transcripts and events are not duplicated downstream, and no participant score is derived or revised.

No generated prose field has a maximum-character constraint. The schema retains lower character guards only, while the manual targets the contract's word ranges. Critiques must contain exactly four sentences, led respectively by `strongest feature:`, `principal limitation:`, `live burden:`, and `locked score:`, and target 108–122 words overall. Repository code validates the untouched model output against the existing 105–130 word contract; it performs no normalization, correction, retry, or prose mutation. Move and Overall Commentary tag arrays are schema-locked empty because v4.2.16 showed that optional post-scoring tag selection is not reliable enough for this compact lane and empty tags are explicitly preferred to forced labels.

The gate uses one fresh ChatGPT-subscription 5.6 Sol/low context per debate, one attempt, no retries, no correction contexts, and isolated temporary homes and source directories. Each debate must validate within 4.5 model-minutes and the three-debate mean must not exceed 4.0 minutes. Transport metadata and raw outputs are retained, and any schema, content, transport, or runtime failure fails closed.

The gate passes only if all three untouched outputs validate and both runtime limits pass. A pass replaces the central finalization assumption with the observed mean, retains 4.5 minutes as the conservative finalization allowance, and authorizes preparation—not execution—of a new disjoint fresh-judgment gate. It does not authorize new scoring, production mutation, or the 195-debate run.
