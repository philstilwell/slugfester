# Slugfester Three-Debate Finalization Gate v4.2.16

This retired replication gate tests the compact finalization lane on Debates 55, 103, and 161. Each fresh 5.6 Sol/low context receives the current workflow, locked scoring rubric, finalization manual, complete source packet, and a debate-specific closed schema. The packet contains every source-grounded move, route, section, audio-verified representative quotation, and calculated score. Raw transcript and event files are not duplicated after participant judgment has closed.

The schema adds character-length guards to the existing reconstruction contract: quote contexts are 130–600 characters, critiques are 800–960 characters, and new AI arguments are 300–850 characters. The manual retains the stricter word-count rules. After model output closes, deterministic code checks summaries, quote contexts, critiques, and new arguments. A critique over 130 words may be normalized only by the v4.2.15 rule that protects its strongest-feature, principal-limitation, live-burden, and locked-score sentences and removes the shortest remaining sentence while retaining at least 105 words. Short fields and all other violations fail closed.

The unchanged complete reconstruction validator then checks locked score and source identity, section coverage, word limits, quotation identity, Overall Commentary minimums, AI Extension balance and novelty mappings, disclosure, accordion metadata, byline, and prohibited language. There is one model attempt and no correction context per debate.

The gate passes only if all three outputs validate, each debate completes within 4.5 model-minutes, and the mean is at most 4.0 minutes. A pass replaces the central finalization assumption with the observed mean and retains 4.5 minutes as the conservative finalization allowance. It authorizes preparation—not execution—of a new disjoint fresh judgment gate. It does not authorize new scoring, production mutation, or the 195-debate run.
