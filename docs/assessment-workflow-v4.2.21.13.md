# Slugfester Held-Out Partition Primary A v4.2.21.13

This stage prepares the three held-out partition debates for candidate-grounded Primary Pass A. It makes no model or audio call, derives no score, and reads no predecessor assessment output.

Each context contains the three locked rubrics, the structural-primary manual, one partition source packet, the complete score-blind candidate bundle, an exact sparse source ledger around every candidate, and a debate-specific schema. The schema structurally requires four to six sections, one or two selections from each side per section, and side-specific candidate IDs.

The model authors semantic judgments only. The repository restores section ID, side, speaker, move kind, source span, attribution confidence, exact evidence rendering, and global chronology; then it applies the unchanged v4.2.20 validator. One attempt, no repair, and no score derivation are the only execution policy eligible for later preregistration.
