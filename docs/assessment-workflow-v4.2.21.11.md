# Slugfester Partition Discovery Execution v4.2.21.11

This stage freezes twelve isolated, score-blind source-discovery contexts for the three held-out partition debates. It uses ChatGPT subscription authentication with API keys removed, makes no transcription call, and has zero metered API cost.

Each context receives one debate packet, the discovery manual, one locked chunk schema, and one exact chunk ledger. Other chunks, other discovery outputs, legacy assessments, ratings, scores, winners, and publication prose are unavailable. Every context gets one attempt, no retry, and no semantic correction. Independent later contexts continue after a local failure.

If all twelve outputs validate, the repository compiles one candidate bundle per debate without silently deduplicating semantic candidates. A sparse evidence ledger may deduplicate repeated source rows, but it must contain every selected candidate span plus a bounded twelve-event context flank. Candidate bundle compilation derives only `moveKind`, qualified candidate IDs, and qualified local target IDs. It derives no rating or score.

Passing discovery authorizes candidate-grounded Primary Pass A packet preparation only. It does not authorize Pass A execution, Pass B, audio, adjudication, scoring, publication, production mutation, or the 195-debate run.
