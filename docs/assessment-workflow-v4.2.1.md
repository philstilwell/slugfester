# Slugfester Compact-Transport Fresh-Six Workflow v4.2.1

This prospective gate inherits the complete v4.1.9 judgment and source-integrity contract plus the v4.2 compact input transport. The retired Debate 180 smoke established that one lossless timestamped ledger can replace duplicate transcript/event delivery without changing the source, schema, scoring anchors, output fields, timeout, or deterministic validation. No v4.2 diagnostic judgment can count toward this gate.

## Fresh disjoint sample

Repository code selects six dyadic debates from the frozen source-only metadata pool after this workflow, validator, schema, fixtures, and selector are committed. It excludes every debate previously retired or used in calibration, including all v4.1.7, v4.1.8, and v4.1.9 fresh samples. No legacy score, critique, winner, tag, publication prose, or prior judgment may enter selection.

The sample contains one debate from each predeclared topic family:

1. resurrection and historical Christianity;
2. morality and ethics;
3. mind, consciousness, free will, and personal identity;
4. evil, suffering, hiddenness, hell, and salvation;
5. science, origins, cosmology, evolution, and fine-tuning; and
6. general theism and religion.

Duration stratification requires at least one debate under 90 minutes, at least one from 90 through 120 minutes, at least one over 120 minutes, and no more than three over 120 minutes. Within these constraints, a fixed v4.2.1 salt ranks candidates by family and debate ID, and deterministic dynamic programming chooses the minimum aggregate family rank with a stable debate-ID tie break. Sample identity, selector hash, source hashes, and the no-legacy-access boundary lock before model execution.

## Compact primary transport

For each selected debate, the original `transcript.txt`, `events.json`, and `manifest.json` remain stored locally and hash-locked. Repository code generates one JSONL ledger with rows `[eventIndex, startMs, durationMs, text]`. The ledger must replay exactly to every original normalized event and pass its frozen SHA-256 before execution.

The isolated primary model receives the complete v4.0, v4.0.1, and v4.1 rubrics, one consolidated v4.2.1 primary manual, the source-only packet, the lossless source ledger, and the enforced schema. It does not receive a duplicate plain transcript, the original event file, historical workflow amendments irrelevant to primary judgment, legacy material, other debates, control status, prior judgments, or publication prose.

## Unchanged judgment and source rules

Each Sol/low primary context remains one attempt with no retry, no normalization, and a 30-minute cap. The judge selects four to six sections and the minimum eight-to-twenty-four moves preserving every load-bearing route and decisive exchange, with one or two moves per side per section.

Every raw source span contains only event indices and an excerpt. The endpoint schema caps excerpts at 600 characters; deterministic validation requires 12–100 lexical tokens, at least 0.80 lexical recall, and at least 0.80 ordered coverage against only the declared original events. Repository code alone derives milliseconds. Any source hash, ledger replay, event range, excerpt, schema, transport, or inherited judgment-validation failure stops the gate without retry.

## Consensus, audio, scoring, and compression order

After all primary outputs pass, repository code derives chronology and provisional trigger values without publishing scores. Every medium- or low-confidence source attribution requires audio verification before Pass B or disagreement extraction. Every deterministic escalation receives an isolated Sol/high Pass B over the locked inventory and complete compact source ledger. Disagreements are extracted mechanically; a third isolated Sol/high context adjudicates only disputed supplied candidates. Scores derive only after required audio and adjudication close and one final scoring-input ledger locks.

All six debates receive the inherited score-blind compression audit before score derivation. No legacy comparator is opened until the new score artifact is immutable. AI Extension material remains outside all participant judgment and scoring contexts.

## Gate acceptance

The gate passes only if:

1. all six original source chains and compact ledgers validate and replay exactly;
2. all six primary contexts pass on one attempt within the frozen transport limits;
3. every source excerpt passes schema-bounded event-aware validation and deterministic time compilation;
4. every required trigger, audio check, Pass B review, disagreement, dependency, and adjudication is honored;
5. all six compression audits find no substantiated material omission;
6. every final ledger passes exact deterministic replay and one scoring-pass validation;
7. the inherited frozen legacy winner, score-drift, and margin-drift thresholds pass after score lock; and
8. the measured 195-debate projection remains at most 52 central hours and 60 conservative hours.

A failure is reported unchanged and stops the gate. A passed v4.2.1 gate authorizes preparation—but not execution—of a preregistered held-out end-to-end gate. The 195-debate reassessment remains unauthorized until that held-out gate passes and explicit editorial promotion is recorded.
