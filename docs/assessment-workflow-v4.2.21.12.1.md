# Slugfester Simplified Discovery Successor Gate v4.2.21.12.1

This stage reruns all twelve score-blind partition contexts under the simplified v4.2.21.12 response-intent contract. It reuses exact source plans and ledgers but no predecessor model output. Authentication is the ChatGPT subscription with API keys removed; metered API and transcription cost ceilings are zero.

Every context is isolated, gets one attempt and no retry, and continues independently after a local failure. Validation requires exact source replay, core start-event ownership, chronological candidates, complete core review, bounded candidate count, and the two-field response intent. No rating or score is derived.

All twelve contexts must validate before deterministic candidate bundle compilation. Candidate compilation qualifies IDs, derives `moveKind`, retains target descriptions, performs no semantic deduplication, and builds an exact sparse source ledger containing all candidate spans plus twelve event rows of context. Passing authorizes Primary Pass A packet preparation only.
