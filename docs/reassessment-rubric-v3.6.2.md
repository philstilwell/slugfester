# Slugfester Reassessment Rubric v3.6.2

Version 3.6.2 uses the v3.6 decision-card anchors and the v3.6.1 unique-evidence rule unchanged.

Return only the requested family card. Defaults require null evidence. Active evidence must be exact, unique source text. Diagnostics and dual-positive reframes require a relation span containing both cues plus an eligible explicit link cue. Burden decisions are limited to the two blinded candidates or `neither`.

No score, critique, Overall Commentary, AI Extension, winner, or production assessment may appear.
