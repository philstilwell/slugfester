# Slugfester Fresh Direct-Lane Judgment Gate v4.2.18

This calibration stage prepares a genuinely disjoint three-debate test of the v4.0 consolidated primary judgment lane after the v4.2.17 finalization gate passed. It tests only the direct source-ledger route: dyadic debates shorter than 90 minutes with complete hash-valid local transcript chains. Longer debates remain assigned to a separately validated partition-and-integration route and cannot enter this sample.

Selection is source-only and fixed before any candidate transcript or legacy assessment is opened. Repository code excludes every retired debate, every v4.1.6 development debate, and every debate selected by the v4.1.7 through v4.2.4 fresh-gate series. It classifies motions into the existing six topic families, ranks eligible debate IDs with a fixed v4.2.18 salt, and chooses the minimum aggregate-rank triple spanning three distinct families. Candidate ranks are not inspected before the algorithm and salt are committed. A separate deterministic motion-only screen must confirm a substantive family anchor before packet preparation.

Each packet contains neutral debate metadata and a complete lossless timestamped JSONL source ledger compiled from the locally stored events. The original `transcript.txt`, `events.json`, and `manifest.json` remain local and hash-authoritative. Legacy scores, winners, critiques, tags, prior inventories, prior burdens, and publication prose are unavailable. The primary schema uses the v4.2.6 conservative excerpt contract: 8–24 chronological moves, four-to-six sections, one-to-two moves per side per section, 12–100 lexical tokens and no more than 450 characters per excerpt, repository-owned timestamps, and no calculated scores or publication prose.

Preparation freezes one hidden control debate for the later risk-triggered consensus stages, but this stage authorizes no model context. A later preregistration may authorize one isolated ChatGPT-subscription 5.6 Sol/low primary attempt per debate, with no retry, normalization, truncation, score derivation, production mutation, or 195-debate execution. Passage of a primary gate would authorize only the next deterministic validation and risk-extraction stage.
