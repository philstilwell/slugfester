# Slugfester Atomic-Bundle Compiler Workflow v3.7.2

Version 3.7.2 is a zero-cost retrospective development replay. It compiles the frozen v3.7.1 scalar audit decisions into atomic semantic bundles without requesting new model judgments, changing the retired key, or producing debate scores or prose.

## Atomic units

- Target components and their contrary disposition form one bundle. Component contact remains a model judgment; the contrary disposition is derived mechanically.
- A reframe bundle contains malformed-demand presence, replacement-demand presence, and relation kind. A non-`none` relation is permitted exactly when both clauses are present.
- A diagnostic bundle contains defect type and, when a consequence is already locked as present, the relation kind. An active consequence requires an active defect and non-`none` relation.
- Example and burden choices remain candidate-bound singleton bundles.

## Replay rules

1. Preserve every v3.7.1 output and candidate mapping unchanged.
2. Map anonymous options to semantic values deterministically.
3. Compile each initial pass independently. Reject an incoherent bundle; do not repair it or borrow a value from another pass.
4. Measure agreement on complete valid bundles, not dependent scalar fields.
5. Compile the frozen two-vote final decisions separately and require every final bundle to be coherent.
6. Report compiler mechanics separately from semantic repeatability. A compiler pass cannot authorize a model gate, held-out access, scoring, prose, or production mutation.

All replay inputs have high speaker-attribution confidence. No audio verification, model execution, transcription, API call, or external paid service is part of v3.7.2.
