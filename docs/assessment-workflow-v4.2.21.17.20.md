# Slugfester Hard-Route Held-Out Discovery Gate v4.2.21.17.20

This gate subjects all twenty isolated discovery contexts from the five fresh hard-route held-out debates to the production-shaped score-blind discovery protocol. It may launch only from a frozen manifest that consumes a passing retired transport canary no more than twenty-four hours old.

The scheduler expands deterministically from one context to two and then to four concurrent contexts. Every context in a ramp phase must validate before the next phase may begin. A ramp failure stops unattempted phases; after the ramp passes, independent contexts in the four-worker phase continue so the single permitted execution yields a complete failure record. Each context receives one attempt, no retry or repair, and a five-minute timeout. Transport failures preserve separate stdout and stderr tails, while validation failures additionally preserve validator diagnostics.

The model sees one transcript chunk, its source packet, the discovery manual, and a schema enforcing owned-core start bounds, available-context end bounds, and the frozen two-interlocutor speaker allowlist. It cannot see other chunks, prior judgments, ratings, scores, winner labels, publication prose, or local target topology.

Passing requires all twenty contexts to validate and the compiled inventory for each debate to contain at least eight candidates, including at least four from each side. Compilation transports every discovered candidate without silent semantic deduplication and derives only repository-defined move kinds. This gate derives no score and authorizes only preparation of isolated independent-judgment packets.
