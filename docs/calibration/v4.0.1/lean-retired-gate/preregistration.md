# v4.0.1 lean retired-control gate preregistration

This gate inherits the v4.0 retired-control sample, comparator thresholds, source rules, trigger policy, cost ceiling, one-attempt rule, and promotion boundary. It replaces the failed v4.0 schema prospectively by removing model-supplied precision/clarity and epistemic-calibration scalar values and deriving them mechanically from closed findings.

The retired controls remain Debates 55, 103, and 161. Their v3.8.11 comparator scores and winners remain prohibited from all model contexts and are accessed only after v4.0.1 final scores close. The gate still requires 3/3 matching winners, maximum absolute side-score delta 5, all required audio checks, correct trigger behavior, zero calculator mismatches, a central projection at most 52 hours, and a conservative projection at most 60 hours.

Before any real-debate call, the exact v4.0.1 endpoint schema must pass one frozen synthetic context on its first attempt. The failed v4.0 output cannot be normalized, reused, or counted. A passed v4.0.1 retired gate authorizes only a separately preregistered ten-debate held-out gate.
