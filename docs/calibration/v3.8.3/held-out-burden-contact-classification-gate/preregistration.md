# v3.8.3 held-out burden-contact classification preregistration

## Purpose

This continuation tests whether the v3.7.6 composite burden-contact rule remains repeatable on 12 moves selected from three previously held-out, fully reconstructed dyadic debates. It tests one semantic component only. It is not a truth benchmark and does not assess or score either participant.

## Locked source boundary

The sole source inventory is the passed v3.8.2 adjudicated inventory. Four moves per debate enter packet construction only after every source field has two matching votes and every required audio check is complete. The packets copy the locked atomic excerpt, source coordinates, speaker and side, and two route maps. They exclude the source-preparation proposition summary, provisional burden contact, selection warning, attribution rationales, review output, and adjudication rationale.

Each packet is accompanied by the hash-verified full local transcript and timestamped event file. Packet construction deterministically verifies every atomic excerpt against exactly one event span and confirms that all selected attributions are high confidence. No new transcript or paid API call is permitted.

## Composite universe and counterbalancing

Every move receives the complete two-route universe: no route contact plus support and attack for each of ten exact bridges, for 21 composite candidates. The same semantic universe appears in both passes, but every semantic tuple receives a different anonymous option position in pass A and pass B. The sealed option map and provisional source-preparation aids are never model-visible.

## Classification and resolution

Each debate receives two isolated 5.6 Sol classification contexts at high reasoning. A deterministic extractor decodes option IDs and compares complete semantic tuples. A third isolated context receives only disputed moves, with the two initial tuples anonymized and counterbalanced, and may select no third value. Every final move requires two matching votes.

The gate requires at least 11 initial agreements across 12 moves, at most one initial disagreement, no invalid bundle, all 12 final moves resolved by two votes, and the frozen minimum category coverage. Failure stops the workflow. Passage may authorize preregistration of a separate score-derivation and assessment-reconstruction gate; it does not authorize scores, prose, benchmark changes, production changes, or all-debate rollout.

## Transport and cost

Each context receives one inference attempt, no output retry, and a 60-minute timeout. Same-request recovery is counted only from an anchored `WARN codex_core::responses_retry` record and is limited to two per context. ChatGPT subscription authentication is used with API keys removed. Metered model API and transcription costs must remain $0.
