# v3.3 anonymous bundled adjudication calibration

This directory contains the frozen retired-development bake-off for Workflow and Rubric v3.3. It reuses v3.2's accepted source chain, gold keys, and independent Terra/Sol raw passes by immutable hash. Only the adjudication layer is new.

The test compares complete Terra and Sol blind-adjudication variants. It cannot blend them, open held-out transcripts, calculate participant scores, or modify production debate objects.
