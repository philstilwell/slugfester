# v2.7 lane-specific classification development

v2.7 keeps multi-speaker debates in scope while separating dyadic and multi-speaker readiness. It converts the retired v2.6 disagreements into development fixtures, preserves the successful graph/contact, burden, reframe, source, and hard-gate controls, and introduces orthogonal target-object/scope/burden primitives plus an explicit diagnostic-object/impact-link model.

The dyadic and multi-speaker gates are independently promotable. Neither gate, even if passed, directly authorizes production scoring. No development or classification artifact may update scores, prose, Overall Commentary, AI Extension, rankings, or rendered debate pages.
