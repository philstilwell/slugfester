# v2.6 target-contact calibration

v2.6 repairs the target-contact layer that failed the v2.5 held-out gate. It preserves the successful v2.5 mechanism and burden models, converts the retired v2.5 sample into development data, and requires a new metadata-selected held-out gate before numerical scoring.

No v2.6 development or held-out artifact may update production scores, prose, Overall Commentary, AI Extension, rankings, or rendered debate pages.

The preregistered held-out gate did not pass. The typed component-contact model reached its threshold, but target-relation, responsive-only coverage, and diagnostic-mechanism judgments did not generalize across the fresh sample. No numerical or corpus-wide stage is authorized.
