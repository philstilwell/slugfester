# v2.3 three-debate controlled gate

This directory records the preregistered v2.3 rerun of Debates #05, #81, and #95. It reuses the hash-verified v2.2 transcript, inventory, and audio-verification chain and adds a blind two-pass response-classification stage before the unchanged two-pass numerical scoring stage.

Artifact order is: manifest → inventories → classifier A/B → response locks → scorer A/B → numerical adjudication → ledgers → reliability decision. Scorecards, AI Extensions, novelty maps, and rendering QA are produced only if classification and numerical reliability both pass.
