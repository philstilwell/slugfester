# v3.8 held-out source-preparation manual

This manual governs source preparation only. Do not score either participant and do not write assessment prose.

## Proposal role

Read the complete transcript and timestamped event file. Define one neutral burden route for each side: a concise route description, observable success criteria, one motion bridge, one central bridge, and three proposition-specific subsidiary bridges. A bridge states a claim that a move can actually support or attack; it is not a topic label or a generic catch-all.

Select eight atomic argumentative moves, four per named participant. Spread them across the substantive exchange and prefer passages whose inferential role can be recovered from a bounded event span. Exclude introductions, logistics, moderator summaries, and audience assertions unless a participant expressly adopts them. Record event indices exactly. Each span should contain enough context to identify one proposition without combining separate arguments.

For selection balance only, assign each candidate a provisional composite: no route contact, support for one exact bridge, or attack on one exact bridge. This provisional value is hidden from classification reviewers and is not a truth key. Use no contact when the move is important or responsive but does not supply a reason for or against a stated bridge.

Speaker attribution is `high` only when the turn boundary, self-reference, address, or position-specific content makes the named speaker clear from the full transcript. Use `medium` or `low` when the auto-caption stream leaves a real alternative. Do not infer identity merely from which side would benefit from the claim.

## Review role

Read the same complete transcript and event file, then review the proposal-derived packet without access to its provisional contacts, attribution judgments, or selection rationales. Decide whether each proposed route and bridge is a faithful, proposition-specific representation of that side's live burden. Decide whether each candidate span is a valid atomic argumentative move, identify its speaker and side independently, assign attribution confidence, and make an independent provisional composite classification.

Reject a route or bridge only for a material source-grounding defect, not because you would prefer different wording. Reject a move when the span is non-argumentative, combines distinct moves, lacks enough context, or cannot be attributed reliably enough even with required audio review. Preserve uncertainty explicitly.

## Shared prohibitions

Do not consult legacy assessments, gate thresholds, prior gate results, other reviewer outputs, provisional reference expectations, scores, participant critiques, Overall Commentary, or AI Extension. Return only the required schema-conforming JSON.
