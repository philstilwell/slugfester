# v3.0 adjudicated-consensus calibration

This calibration line tests whether two independent 5.6 Sol primitive passes plus dispute-only adjudication can produce a sufficiently accurate final lock even when raw passes disagree.

The first gate is `retired-three-debate-test/`, containing Debate #62 (straightforward dyadic), Debate #185 (difficult dyadic with reframe boundaries), and Debate #154 (multi-speaker). All source material and gold cases were exposed before v3.0 and are permanently retired from future held-out use.

No artifact in this directory may update production scores, prose, Overall Commentary, AI Extension content, rankings, or rendered debate pages. A passing retired test authorizes only preparation of a new disjoint held-out gate.
