# v3.7.3 atomic-bundle correction-smoke assessment

## Outcome

The preregistered v3.7.3 correction smoke passed. All six isolated 5.6 Sol contexts produced valid outputs on their sole attempt, and the two initial passes agreed on all eight complete atomic bundles. The result exceeded the seven-of-eight initial-agreement threshold, resolved all eight bundles with two votes, and required no adjudication context.

The three bundles that had disagreed in the v3.7.2 replay—`diagnostic-154-15`, `target-154-08-components`, and `reframe-185-08`—all received matching fresh votes in v3.7.3. The previously incoherent reframe tuple was unavailable by construction, and neither new pass produced an invalid bundle.

## What the result establishes

The exposed candidate-bound atomic format is highly repeatable on this eight-bundle sample. Complete anonymous options eliminated the scalar-combination defect and reduced the model's task to choosing among coherent semantic tuples. Counterbalancing also worked: the two passes selected the same semantic values despite different option positions.

The execution controls worked as designed. Each context saw only the workflow, rubric, smoke manual, schema, and its own packet. The sealed option-origin map and other-pass outputs remained unavailable. Subscription authentication was copied into a temporary isolated home, API keys were removed, and no retry, repair, scoring, or paid transcription path was used.

## What the result does not establish

Five of the eight two-vote results differ from the retired expected values. That is diagnostic evidence that the retired key is unreliable; it is not authority to replace that key. Two isolated runs of the same model can share a systematic interpretive error, especially when cases are exposed and candidates constrain the answer space.

The sample is also small, contains only three debates, and was selected from known prior trouble spots. Because initial agreement was perfect, the live run did not exercise the disputed-bundle adjudication branch. All source attributions were high confidence, so the medium-confidence audio-verification rule was not implicated.

## Quality judgment

For its narrow purpose—testing whether coherent atomic options improve same-model repeatability—the workflow performed at an **A level**. For semantic correctness and generalization to production debates, the evidence remains **provisional**. The overall workflow is therefore not yet ready for the 195-debate reassessment batch.

The preregistered pass authorizes only the next step: preregistration of a disjoint retired atomic-bundle test. That test should use previously unexposed debates and bundle instances, retain two isolated Sol passes plus dispute-only adjudication, include a deterministic disagreement-branch fixture before execution, and preserve the rule that no score or prose is derived until semantic choices are adjudicated.
