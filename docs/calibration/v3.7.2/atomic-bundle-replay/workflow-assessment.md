## Recommended v3.7.3 development step

Build and dry-test atomic output packets before any new model context:

1. Ask the model only for independent judgments. Omit target contrary disposition from model output and derive it after validation.
2. Make every diagnostic response an atomic defect/consequence object and every reframe response an atomic malformed/replacement/relation object.
3. Reject incompatible bundles before comparing passes; permit no model retry or discretionary repair.
4. Compare complete bundle tuples and send only disputed bundles—not scalar subfields—to a third isolated pass.
5. Use synthetic positive and negative bundles to prove schema and validator behavior locally, then run a subscription-backed structured-output smoke only after a new frozen cost statement and preregistration.
6. Treat any repeat on the same eight exposed bundles as a correction smoke, not a promotion gate. A later disjoint retired sample remains necessary.
7. For a future eight-bundle correction smoke, preregister at least **7 of 8** initial bundle agreements, zero invalid bundles, and complete two-vote resolution. Do not lower that threshold after execution.

The next authorized action is therefore local v3.7.3 packet/schema development. Fresh model execution remains blocked until those artifacts and their dry fixtures pass and are frozen.
