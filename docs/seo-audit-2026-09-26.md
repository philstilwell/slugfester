# Site-wide SEO audit — 26 September 2026

## Published improvements

- Dedicated, internally linked pages for all 15 topic categories. Each includes the existing category explanation, every matching assessment, a stable address, its own title and description, and topic-specific structured information.
- More informative search descriptions for debate and profile pages, drawn from their actual debate questions and existing biographies. No scores, biographies, or assessment conclusions were rewritten.
- Source-backed fallacy and cognitive-bias examples in the initial HTML, so readers and crawlers do not need JavaScript to reach useful material.
- Corrected the topic index's structured list: it now describes the 15 topics, not a list of debates labeled as topics. Added explicit page identities for the home, reference, and research-method pages.
- Profile sharing cards use the existing speaker portraits, with accurate dimensions and image descriptions. All 182 published portraits were checked as 512 × 512 pixels.
- Consistent initial and browser-generated metadata, including profile record ordering and rankings descriptions that no longer change with interactive filters.
- Sitemap and page modification dates are derived from persisted content fingerprints. Rebuilding without substantive changes preserves the date; changing content updates it. Dates are shared with browser-generated structured information.
- Crawl rules discourage indexing internal scripts, tests, and assessment-production records. Public code, images, and research PDFs remain crawlable. Robots rules are crawl guidance, not access protection.
- Automated checks cover all 487 indexed pages, unique titles/descriptions/canonical addresses, topic membership, reference evidence, metadata relationships, versioned resources, and stable modification dates.

## Existing strengths verified

HTTPS and www redirects resolve to the preferred domain. Unknown production addresses return a real 404. Existing debate and profile pages include substantive initial HTML, source links, biographies, and assessment limitations. Legacy addresses retain their existing handling. No review stars, endorsements, or unsupported rich-result claims were added.

## Maintenance and follow-up

Run the normal SEO generator when publishing or editing content and commit its page-history files with the generated output. The website-quality checks enforce freshness and consistency.

The remaining search-performance follow-up requires the site's Google Search Console property: submit or confirm the sitemap, inspect representative topic/debate/profile pages, and monitor indexed pages and search queries. This audit did not inspect private Search Console data or promise a ranking increase. Search engines decide whether and when to crawl, index, or display a given page or snippet.
