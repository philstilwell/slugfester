# Slugfester Held-Out Discovery Gate v4.2.21.17.11

This gate runs the five newly frozen held-out debates through uniform score-blind source discovery. Seventeen isolated 5.6 Sol contexts review exactly one source chunk each. Every context receives a fresh source directory and a fresh temporary Codex home; other chunks, model outputs, prior judgments, scores, winners, and publication prose remain unavailable.

The frozen scheduler allows at most four concurrent contexts in deterministic input order. Each context receives one attempt, with no retry or semantic repair. Authentication uses the ChatGPT subscription with API credentials removed, so the maximum metered model and transcription cost is zero.

After all seventeen outputs validate, deterministic compilation transports every discovered candidate. It performs no semantic deduplication or move selection, derives move kind only from the frozen discovery response class, and defers reply topology to the independent judgment stage. Each debate must retain at least eight candidates and at least four candidates per side. No score is derived here.

Passing this gate authorizes only preparation of two independently anonymized judgment packets per held-out debate. It does not authorize judgment execution, audio calls, adjudication, scoring, publication, mutation of production assessments, or the 195-debate run.
