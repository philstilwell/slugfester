# Slugfester Reassessment Rubric v4.1

This amendment inherits the complete v4.0 and v4.0.1 scoring anchors. It changes inventory selection and model allocation, not the meaning or weight of any score.

## Bounded selection rule

Select the minimum set of moves that preserves every load-bearing route and decisive exchange within four to six contested sections. Each section contains one or two actual moves per side. Prefer, in order:

1. the clearest constructive statement of each motion or central bridge;
2. the strongest reply to that statement;
3. a reply that materially changes the surviving warrant, scope, or burden status; and
4. a subsidiary move only when omitting it would misstate route completion.

Do not select repeated restatements, illustrative examples already captured by a stronger proposition, moderator summaries, audience reactions, biographical remarks, or merely rhetorical reinforcement. When a later span materially strengthens an earlier proposition, select the stronger span rather than scoring both unless the later move independently changes response status.

Inventory compression never raises a rating. Omitted repetition supplies no bonus, and an omitted response cannot be treated as if it occurred. Every selected move continues to receive the exact v4.0/v4.0.1 response, burden, precision, calibration, charity, confidence, and duplicate-penalty controls.

## Medium-effort primary and high-effort review

The medium-effort primary judge makes all raw judgments under the unchanged anchors. Sol/high Pass B independently judges every locked move only when a deterministic trigger fires. Candidate-bound Sol/high adjudication resolves only disputed fields. Repository code derives scores only after required review closes.

The AI Extension remains outside the transcript, outside participant scoring, visibly identified as AI-authored, stylistically distinct, and default-collapsed immediately after Overall Commentary.
