Belief bias

Belief bias: Judging an argument by whether its conclusion feels believable instead of evaluating whether the conclusion follows from the premises.

Browse debates Search scorecards Browse topics Compare interlocutors Read the assessment method Explore research insights Read the in-depth CogBias entry

How to interpret this label

A label identifies a specific problem in the reasoning, not a judgment about the person. It adds no separate numerical penalty. See the assessment standards.
